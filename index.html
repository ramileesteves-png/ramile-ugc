Como editar o site

  • Textos: clique em qualquer texto com contorno suave e digite. Salva sozinho.
  • Caixa de texto: com o texto selecionado, use Alinhar (Esq · Centro · Dir), Largura −/+ e Altura −/+. Arraste o ◇ no topo para mover a caixa; o canto inferior direito redimensiona. ↺ reseta. Tudo entra no backup.
  • Foto de capa / Sobre / Estilo: no modo edição, use “Trocar foto” em cima da imagem (capa do site, foto Sobre, e cada card de Estética & nichos). Escolha um arquivo — fica salvo neste navegador. Nos cards de nicho, a galeria abre só por “Ver exemplos”.
  • Galeria — Stories: use “+ Adicionar vídeo” acima dos stories e escolha um arquivo do celular/PC. O × no canto tira da página (dá para restaurar em “Itens ocultos”).
  • Galeria — abas Estilo / Nós dois: clique no card da aba; no modal use “+ Adicionar foto ou vídeo”, arraste para reordenar e × para remover.
  • Layout — tamanho: clique num card/foto/vídeo — aparece “Tamanho − / +” (P · M · G) e “Trocar foto” quando for imagem.
  • Layout — ordem: arraste o card para trocar a disposição na grade.
  • Backup: Exportar/Importar JSON (textos, caixas, ocultos, tamanhos, ordem, galerias, fotos trocadas). Arquivos novos ficam neste navegador.
  • Publicar: (só no modo edição) envia textos/layout e fotos trocadas (até ~1,5 MB cada) para o GitHub Pages. Sem Publicar, a Trocar foto fica só neste navegador. Fotos já publicadas não são apagadas se uma nova publicação falhar ao reenviar a imagem. Vídeos grandes: coloque em assets/.
  • Sair: “Sair do modo edição” — visitantes não veem a barra nem Publicar.

    Configurar publicação

    Publique de graça no GitHub Pages. O token fica só neste navegador (localStorage) — nunca no código do site.

    1. Conta GitHub: criar ou entrar.
    2. Repositório público ramile-ugc com o site (já pode estar criado no GitHub) + Pages em branch main pasta /.
    3. Token (só você cria — aparece uma vez): gerar PAT classic com escopo repo → Generate token → copiar.
    4. Cole usuário, repositório ramile-ugc e o token abaixo → Salvar → use Publicar na barra.

    Opcional: Cloudflare Pages também é grátis — conecte o mesmo repositório GitHub no painel da Cloudflare. O fluxo Publicar desta página usa GitHub Pages.
